# Osteria Sera — versione autonoma

Sorgenti completi React + TypeScript + Vite, con risorse locali. Node.js 22.13 o successivo.

```sh
npm ci
npm run dev
npm run build
npm run preview
```

Pubblica il contenuto di `dist/` su un hosting statico. `npm run build` esegue prima il controllo TypeScript.

La guida completa è nel file `../LEGGIMI.md`. Menu e contatti sono illustrativi; la prenotazione è dimostrativa e non invia richieste.
